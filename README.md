# PPI Plâtrerie Peinture

Nuxt website for PPI Plâtrerie Peinture.

The site is available in French and English. Use the FR/EN selector in the header; your choice is saved for future visits.
Photos use same-name WebP files when supported, with JPEG fallbacks.

## Requirements

- Node.js
- npm

## Development

Install dependencies and start the development server:

```sh
npm install
npm run dev
```

The site is available at `http://localhost:3000`.

## Production build

```sh
npm run build
npm run preview
```

To generate a static site, run `npm run generate`.
