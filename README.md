# PPI Plâtrerie Peinture

Nuxt website for PPI Plâtrerie Peinture.

## Requirements

- Node.js
- npm

## Development

Install dependencies and start the development server:

```sh
npm install
npm run dev
```

The site is available at `http://localhost:3000`.

## Production build

```sh
npm run build
npm run preview
```

To generate a static site, run `npm run generate`.
